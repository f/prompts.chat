## المبدأ الثامن: تحقق وتأكد

لا تثق بشكل أعمى في مخرجات النموذج، خاصة للمهام المهمة.

### اطلب التفكير


### اطلب وجهات نظر متعددة

```
أعطني ثلاث طرق مختلفة لحل هذه المشكلة.
لكل طريقة، اشرح المفاضلات.
```

### أدرج التحقق الذاتي

```
بعد إنشاء الكود، راجعه بحثاً عن:
- أخطاء في الصياغة
- الحالات الحدية
- الثغرات الأمنية

```
