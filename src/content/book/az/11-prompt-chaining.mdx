        Bu xülasə və varlıqlara əsasən biznes analitiki üçün
        tətbiq oluna bilən 3 fikir irəli sür.
        Xülasə: {summary}
        Varlıqlar: {entities}
    """)
    
    return {
        "summary": summary,
        "entities": json.loads(entities),
        "insights": insights
    }`}
/>
