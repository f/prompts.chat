# Awesome ChatGPT Prompts-un Tarixi

## Başlanğıc: Noyabr 2022

ChatGPT ilk dəfə 2022-ci ilin noyabrında buraxıldığında, süni intellekt dünyası bir gecədə dəyişdi. Bir vaxtlar tədqiqatçıların və tərtibatçıların sahəsi olan süni intellekt birdən-birə hər kəs üçün əlçatan oldu. Bu yeni texnologiyaya valeh olanlar arasında ChatGPT-nin qabiliyyətlərində qeyri-adi bir şey görən tərtibatçı Fatih Kadir Akın da var idi.

> "ChatGPT ilk buraxıldığında, qabiliyyətləri məni dərhal valeh etdi. Aləti müxtəlif yollarla sınadım və nəticələr məni daim heyrətləndirdi."

O ilk günlər təcrübə və kəşflə dolu idi. Dünyanın hər yerindən istifadəçilər ChatGPT ilə qarşılıqlı əlaqə qurmanın yaradıcı yollarını tapır, tapıntılarını paylaşır və bir-birlərindən öyrənirdilər. "Awesome ChatGPT Prompts" fikri məhz bu həyəcan və kəşf atmosferində doğuldu.

## Hər Şeyi Başladan Depo

2022-ci ilin dekabrında, ChatGPT-nin buraxılmasından cəmi həftələr sonra, GitHub-da [Awesome ChatGPT Prompts](https://github.com/f/prompts.chat) deposu yaradıldı. Konsept sadə, amma güclü idi: hər kəsin istifadə edə biləcəyi və töhfə verə biləcəyi, diqqətlə seçilmiş effektiv promptlar kolleksiyası.

Depo qısa müddətdə böyük maraq qazandı və dünya miqyasında ChatGPT istifadəçiləri üçün əsas mənbəyə çevrildi. Faydalı promptlardan ibarət şəxsi kolleksiya kimi başlayan şey, dünyanın hər guşəsindən tərtibatçıların, yazıçıların, müəllimlərin və həvəskarların töhfələri ilə icma yönümlü bir layihəyə çevrildi.

## İlk Kitab: "The Art of ChatGPT Prompting"

Deponun uğuru, 2023-cü ilin əvvəlində Gumroad-da nəşr olunan "The Art of ChatGPT Prompting: A Guide to Crafting Clear and Effective Prompts" hərtərəfli bələdçisinin yaradılmasına səbəb oldu.

Kitab, prompt mühəndisliyinin erkən dövr müdrikliyini əks etdirdi və bunları əhatə etdi:

- ChatGPT-nin necə işlədiyini anlamaq
- Süni intellekt ilə aydın ünsiyyət prinsipləri
- Məşhur "Act As" texnikası
- Addım-addım effektiv prompt yaratmaq
- Tez-tez yol verilən səhvlər və onlardan necə qaçınmaq
- Problem həlletmə məsləhətləri

**Kitab bir fenomenə çevrildi** və Gumroad-da **100.000-dən çox yükləmə** qazandı. Sosial mediada paylaşıldı, akademik məqalələrdə istinad edildi və icma üzvləri tərəfindən bir çox dilə tərcümə edildi. Yüksək səviyyəli təqdirlər gözlənilməz yerlərdən gəldi — OpenAI-nin həmtəsisçisi və prezidenti [Greg Brockman](https://x.com/gdb/status/1602072566671110144) belə layihəni təqdir etdi.

## Sahəni Formalaşdıran Erkən Anlayışlar

O formalaşdırıcı aylarda, prompt mühəndisliyinin əsasını təşkil edəcək bir neçə vacib anlayış ortaya çıxdı:

### 1. Spesifiklik Vacibdir

> "ChatGPT-nin promptlarımı başa düşməsini və uyğun cavablar istehsal edə bilməsini təmin etmək üçün konkret və uyğun dildən istifadənin vacibliyini öyrəndim."

Erkən təcrübəçilər, qeyri-müəyyən promptların qeyri-müəyyən cavablara səbəb olduğunu kəşf etdilər. Prompt nə qədər spesifik və ətraflı olsa, çıxış bir o qədər faydalı olurdu.

### 2. Məqsəd və Fokus

> "Açıq uçlu və ya həddindən artıq geniş promptlar istifadə etmək əvəzinə, söhbət üçün aydın məqsəd və fokus təyin etməyin dəyərini kəşf etdim."

Bu anlayış, sonrakı illərdə inkişaf edəcək strukturlaşdırılmış prompt texnikalarının əsasını qoydu.

### 3. "Act As" İnqilabı

İcmadan ortaya çıxan ən təsirli texnikalardan biri "Act As" nümunəsi idi. ChatGPT-yə müəyyən bir rol və ya persona üzərinə götürməsini söyləməklə, istifadəçilər cavabların keyfiyyətini və uyğunluğunu əhəmiyyətli dərəcədə artıra bilirdilər.

```
Bir javascript konsolu kimi davranmağını istəyirəm. Əmrlər yazacağam və 
javascript konsolunun nə göstərməli olduğunu cavab verəcəksən. Yalnız 
tək bir kod bloku içində terminal çıxışı ilə cavab verməyini istəyirəm, 
başqa heç nə.
```

Bu sadə texnika saysız imkanlar açdı və bu gün hələ də ən geniş istifadə olunan prompt strategiyalarından biri olaraq qalır.

## prompts.chat-in Təkamülü

### 2022: Başlanğıc

Layihə, GitHub Pages-də HTML olaraq render edilən README faylı ilə sadə bir GitHub deposu olaraq başladı. Sadə, amma funksional idi — gözəl ideyaların ətraflı tətbiqlərə ehtiyac duymadığı prinsipinin sübutu.

**Texnoloji Yığın**: HTML, CSS, GitHub Pages

### 2024: UI Yeniləmə

İcma böyüdükcə, daha yaxşı istifadəçi təcrübəsinə ehtiyac da artdı. Sayt, Cursor və Claude 3.5 Sonnet kimi süni intellekt kodlaşdırma köməkçilərinin yardımı ilə əhəmiyyətli UI yeniləməsi aldı.

### 2025: Tam Funksional Platforma

2025-ci ildə prompts.chat bunlarla qurulmuş tam funksional bir platformaya çevrildi:

- **Next.js** veb framework olaraq
- **Vercel** hostinq üçün
- **Süni intellekt dəstəkli inkişaf** Windsurf və Claude istifadə edərək

Platforma indi istifadəçi hesabları, kolleksiyalar, axtarış, kateqoriyalar, etiketlər və inkişaf edən prompt mühəndisləri icmasına malikdir.

### 2026: Bacarıqlar, Botlar və Komandalar

Növbəti addım ayrı-ayrı promptların hüdudlarından çıxdı. 2026-cı ilin əvvəllərində prompts.chat **bacarıqlara** ev sahibliyi etməyə başladı: agentin tapşırıq tələb edəndə yükləyə bildiyi, təlimat və fayllardan ibarət təkrar istifadə oluna bilən paketlər. 2026-cı ilin oktyabrında daim işləyən botlar üçün **Bots** kataloqu açıldı; hər bot öz təlimatları, bacarıqları, rutinləri və ehtiyac duyduğu konnektorlarla birlikdə paylaşılırdı. Qısa müddət sonra bot *birlikdə daha yaxşı* işlədiyi digər botları göstərə bildi və bu cütlüklər **Teams**-ə, yəni adı olan rolları və aralarında etiketli ötürmələri olan, bir prompt ilə birlikdə quraşdırıla bilən bot komandalarına çevrildi. Platformanın MCP serveri də onlarla birlikdə böyüdü; indi süni intellekt köməkçisi söhbətdən çıxmadan promptları, bacarıqları, botları və komandaları axtara, oxuya və yadda saxlaya bilir.

### Native Tətbiqlər

Layihə, SwiftUI ilə qurulmuş yerli iOS tətbiqi ilə vebdən kənara genişləndi və prompt kitabxanasını mobil istifadəçilərə çatdırdı.
